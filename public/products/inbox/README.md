# Inbox visuels produits

Déposez ici vos nouveaux fichiers `.png` ou `.jpg` (noms UUID recommandés).

Puis lancez :

```bash
npm run sync-images
npm run build
```

Les fichiers sont copiés vers `public/products/` et apparaissent dans **Admin → Médias** pour assignation à un produit.

Les doublons macOS (`fichier 2.png`) sont ignorés automatiquement.
